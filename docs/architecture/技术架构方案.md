# 动态连接线动画系统技术架构方案

## 核心需求分析

### 独特挑战
1. **实时跟随**: 头像和消息气泡可单独滚动，连接线需实时更新位置
2. **高性能渲染**: 支持大量连接线的流畅动画
3. **移动端优化**: 触摸交互和性能考虑
4. **灵活性**: 支持多种连接线样式和动画效果

## 技术选择对比

### 渲染技术评估

| 技术 | 性能阈值 | 优势 | 缺点 | 适用场景 |
|------|----------|------|------|----------|
| **WebGL** | 10,000+ 元素 | - 硬件加速<br>- 极高性能<br>- 复杂着色器 | - 学习曲线陡峭<br>- 功耗较高 | 大规模网络图 |
| **Canvas** | 1,000-10,000 元素 | - 性能良好<br>- API简单<br>- 兼容性好 | - 无DOM交互<br>- 单线程限制 | 中等复杂度动画 |
| **SVG** | <1,000 元素 | - DOM集成<br>- 可交互<br>- 矢量缩放 | - DOM开销大<br>- 性能瓶颈 | 简单交互图形 |

### 推荐架构: 混合渲染策略

采用**分层渲染**方案，根据复杂度自动选择最优渲染技术：

```
┌─────────────────────────────────────┐
│           UI Layer (SVG)            │  ← 交互元素、控件
├─────────────────────────────────────┤
│        Connection Layer             │  ← 连接线主体
│    (Canvas/WebGL 自适应)            │
├─────────────────────────────────────┤
│       Background Layer              │  ← 网格、背景
└─────────────────────────────────────┘
```

```typescript
interface ConnectionPoint {

class RealTimeTracker {
  private observers = new Map<HTMLElement, ResizeObserver>();
  private positions = new Map<string, DOMRect>();
  
  trackElement(id: string, element: HTMLElement, callback: UpdateCallback) {
    // 使用 IntersectionObserver + ResizeObserver 组合
    const resizeObserver = new ResizeObserver(() => {
      this.updatePosition(id, element, callback);
    });
    
    const intersectionObserver = new IntersectionObserver(() => {
      this.updatePosition(id, element, callback);
    });
    
    resizeObserver.observe(element);
    intersectionObserver.observe(element);
  }
  
  private updatePosition(id: string, element: HTMLElement, callback: UpdateCallback) {
    const rect = element.getBoundingClientRect();
    const scrollX = window.scrollX;
    const scrollY = window.scrollY;
    
    const position = {
      x: rect.left + scrollX,
      y: rect.top + scrollY,
      width: rect.width,
      height: rect.height
    };
    
    this.positions.set(id, position);
    callback(id, position);
  }
}
```

### 2. 路径计算与优化

```typescript
class PathCalculator {
  // 贝塞尔曲线路径计算
  calculateBezierPath(start: Point, end: Point, options: PathOptions) {
    const distance = Math.sqrt((end.x - start.x) ** 2 + (end.y - start.y) ** 2);
    const curvature = Math.min(distance * 0.3, options.maxCurvature || 100);
    
    const controlPoint1 = {
      x: start.x + (options.startDirection === 'right' ? curvature : -curvature),
      y: start.y
    };
    
    const controlPoint2 = {
      x: end.x + (options.endDirection === 'left' ? -curvature : curvature),
      y: end.y
    };
    
    return { start, controlPoint1, controlPoint2, end };
  }
  
  // 避障算法
  calculateAvoidancePath(start: Point, end: Point, obstacles: Rect[]) {
    const directPath = this.calculateBezierPath(start, end, {});
    const intersections = this.findIntersections(directPath, obstacles);
    
    if (intersections.length === 0) return directPath;
    
    // 使用 A* 算法寻找最优路径
    return this.findOptimalPath(start, end, obstacles);
  }
}
```

### 3. 碰撞检测优化

```typescript
class CollisionDetector {
  private spatialGrid: SpatialGrid;
  
  constructor(worldSize: Size, cellSize: number) {
    this.spatialGrid = new SpatialGrid(worldSize, cellSize);
  }
  
  // 空间分割加速碰撞检测
  detectCollisions(connections: Connection[]): CollisionPair[] {
    this.spatialGrid.clear();
    
    // 将连接线添加到空间网格
    connections.forEach(conn => {
      this.spatialGrid.insert(conn.id, conn.boundingBox);
    });
    
    const collisions: CollisionPair[] = [];
    
    connections.forEach(conn => {
      const candidates = this.spatialGrid.query(conn.boundingBox);
      candidates.forEach(candidateId => {
        if (candidateId !== conn.id && this.lineIntersects(conn, connections.find(c => c.id === candidateId))) {
          collisions.push([conn.id, candidateId]);
        }
      });
    });
    
    return collisions;
  }
}
```

## 渲染器实现

### 1. Canvas渲染器

```typescript
class CanvasRenderer implements IRenderer {
  private ctx: CanvasRenderingContext2D;
  private animationFrame: number;
  
  render(connections: Connection[]) {
    this.ctx.clearRect(0, 0, this.canvas.width, this.canvas.height);
    
    connections.forEach(conn => {
      this.drawConnection(conn);
    });
  }
  
  private drawConnection(connection: Connection) {
    const { path, style } = connection;
    
    this.ctx.beginPath();
    this.ctx.moveTo(path.start.x, path.start.y);
    this.ctx.bezierCurveTo(
      path.controlPoint1.x, path.controlPoint1.y,
      path.controlPoint2.x, path.controlPoint2.y,
      path.end.x, path.end.y
    );
    
    // 渐变效果
    if (style.gradient) {
      const gradient = this.ctx.createLinearGradient(
        path.start.x, path.start.y, path.end.x, path.end.y
      );
      gradient.addColorStop(0, style.startColor);
      gradient.addColorStop(1, style.endColor);
      this.ctx.strokeStyle = gradient;
    }
    
    this.ctx.lineWidth = style.width;
    this.ctx.stroke();
    
    // 动画效果
    if (style.animated) {
      this.drawAnimatedParticles(connection);
    }
  }
}
```

### 2. WebGL渲染器 (高性能版本)

```typescript
class WebGLRenderer implements IRenderer {
  private gl: WebGLRenderingContext;
  private shaderProgram: WebGLProgram;
  private lineBuffer: WebGLBuffer;
  
  private vertexShader = `
    attribute vec2 a_position;
    attribute vec4 a_color;
    uniform mat3 u_matrix;
    varying vec4 v_color;
    
    void main() {
      vec2 position = (u_matrix * vec3(a_position, 1)).xy;
      gl_Position = vec4(position, 0, 1);
      v_color = a_color;
    }
  `;
  
  private fragmentShader = `
    precision mediump float;
    varying vec4 v_color;
    uniform float u_time;
    
    void main() {
      // 动画效果
      float alpha = v_color.a * (0.5 + 0.5 * sin(u_time * 2.0));
      gl_FragColor = vec4(v_color.rgb, alpha);
    }
  `;
  
  render(connections: Connection[]) {
    const vertices = this.generateVertices(connections);
    
    this.gl.bindBuffer(this.gl.ARRAY_BUFFER, this.lineBuffer);
    this.gl.bufferData(this.gl.ARRAY_BUFFER, new Float32Array(vertices), this.gl.DYNAMIC_DRAW);
    
    this.gl.useProgram(this.shaderProgram);
    this.gl.uniform1f(this.gl.getUniformLocation(this.shaderProgram, 'u_time'), performance.now() / 1000);
    
    this.gl.drawArrays(this.gl.LINES, 0, vertices.length / 6);
  }
}
```

## 移动端性能优化策略

### 1. 自适应渲染质量

```typescript
class AdaptiveRenderer {
  private performanceMonitor = new PerformanceMonitor();
  private currentQuality: RenderQuality = 'high';
  
  updateQuality() {
    const fps = this.performanceMonitor.getAverageFPS();
    
    if (fps < 30 && this.currentQuality !== 'low') {
      this.currentQuality = 'low';
      this.applyLowQualitySettings();
    } else if (fps > 50 && this.currentQuality !== 'high') {
      this.currentQuality = 'high';
      this.applyHighQualitySettings();
    }
  }
  
  private applyLowQualitySettings() {
    // 降低帧率
    this.targetFPS = 30;
    // 简化路径
    this.pathSimplification = true;
    // 禁用动画效果
    this.animationsEnabled = false;
  }
}
```

### 2. 触摸优化

```typescript
class TouchHandler {
  private touchStartTime: number;
  private lastTouchPos: Point;
  
  setupTouchEvents() {
    this.canvas.addEventListener('touchstart', (e) => {
      e.preventDefault();
      this.touchStartTime = Date.now();
      this.lastTouchPos = this.getTouchPosition(e.touches[0]);
    });
    
    this.canvas.addEventListener('touchmove', (e) => {
      e.preventDefault();
      const currentPos = this.getTouchPosition(e.touches[0]);
      const deltaTime = Date.now() - this.touchStartTime;
      
      // 防抖处理
      if (deltaTime < 16) return; // 限制60fps
      
      this.handlePan(currentPos, this.lastTouchPos);
      this.lastTouchPos = currentPos;
    });
  }
}
```

## 库选择建议

### 推荐技术栈

1. **主渲染**: Canvas + Konva.js
   - 高性能2D渲染
   - 丰富的动画API
   - 良好的移动端支持

2. **高性能场景**: WebGL + Three.js
   - 处理1000+连接线
   - 复杂着色器效果
   - 硬件加速

3. **轻量场景**: SVG + D3.js
   - 简单交互需求
   - 易于调试和修改
   - 良好的可访问性

### 具体实现建议

```typescript
// 主架构类
class ConnectionAnimationSystem {
  private renderer: IRenderer;
  private tracker: RealTimeTracker;
  private pathCalculator: PathCalculator;
  
  constructor(config: SystemConfig) {
    // 根据需求自动选择渲染器
    this.renderer = this.selectRenderer(config);
    this.tracker = new RealTimeTracker();
    this.pathCalculator = new PathCalculator();
  }
  
  private selectRenderer(config: SystemConfig): IRenderer {
    if (config.connectionCount > 1000) {
      return new WebGLRenderer(config);
    } else if (config.connectionCount > 100) {
      return new CanvasRenderer(config);
    } else {
      return new SVGRenderer(config);
    }
  }
}
```
